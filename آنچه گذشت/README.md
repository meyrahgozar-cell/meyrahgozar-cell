# ریل — مستندی از یک زندگی

روایتی خصوصی و تک‌صفحه‌ای از یک زندگی؛ هر روز یک «قاب»، هر قاب با یک عکس.
کاملاً فارسی و راست‌به‌چپ، تقویم شمسی و اعداد فارسی.

فقط جاوااسکریپت خالص — بدون فریم‌ورک، بدون مرحلهٔ ساخت، بدون کد سرور.

---

## اجرا

هر سرور فایل ایستا کار می‌کند:

```bash
python3 -m http.server 3000
# سپس http://localhost:3000
```

باز کردن مستقیم `index.html` از روی دیسک کار **نمی‌کند** (ماژول‌های ES و سرویس‌ورکر
به origin نیاز دارند).

---

## دو گنجینه، یک رابط

| | گنجینهٔ محلی | گنجینهٔ ابری |
|---|---|---|
| حساب لازم دارد | نه | بله |
| محل ذخیره | IndexedDB روی همین دستگاه | Supabase Postgres + Storage |
| عکس‌ها | blob روی دستگاه | باکت خصوصی، پیوند امضاشده |
| همگام‌سازی بین دستگاه‌ها | نه | بله |

برنامه با هر کدام که در دسترس باشد بالا می‌آید. اگر نشستی نباشد یا جدول‌های ابری ساخته
نشده باشند، همه‌چیز محلی کار می‌کند — و بعداً از تنظیمات ← گنجینه و همگام‌سازی ←
«وارد کن» قاب‌های محلی به ابر می‌روند.

### روشن کردن گنجینهٔ ابری

1. در پروژهٔ Supabase → **SQL Editor** → New query.
2. محتوای [`supabase/schema.sql`](supabase/schema.sql) را بچسبان و اجرا کن (idempotent است).
3. در ریل، صفحهٔ **راه‌اندازی ابر** (`#/setup`) را باز کن و «دوباره بررسی کن» را بزن؛ یا
   اول وارد شو تا خودکار به ابر سوییچ شود.

این اسکریپت می‌سازد:

* `reel_profiles`، `reel_threads`، `reel_entries` — همه با row level security
* تریگری که با ثبت‌نام هر حساب یک نمایه می‌سازد
* باکت خصوصی `reel-media` با سیاست پوشه‌ای برای هر کاربر

## هوش مصنوعی: اصلاح متن در چهار سطح

دکمه‌های چهارسطحی در کنار ویرایشگر، متن قاب را به تابع لبه‌ای `diary` می‌فرستند:

| سطح | نام | یعنی |
|---|---|---|
| ۱ | اصلاح ضروری | فقط غلط املایی، نیم‌فاصله و نشانه‌گذاری؛ کلمه‌ای جابه‌جا نمی‌شود |
| ۲ | ویرایش | زبان روان می‌شود، اما هیچ مفهوم یا مطلب تازه‌ای اضافه نمی‌شود |
| ۳ | گسترش | متن را ویرایش می‌کند و جزئیات هم‌خوان با خودِ متن را می‌افزاید |
| ۴ | آفرینش | تخیل می‌کند، می‌افزاید و روایت را کامل می‌کند |

مدل پیش‌فرض `openrouter/free` است؛ تابع، **مدل واقعیِ همان اجرا** را برمی‌گرداند و در
پایگاه داده ذخیره می‌شود. هر اجرا رأی 👍/👎 می‌گیرد و در تنظیمات ← هوش مصنوعی جدول
امتیاز مدل‌ها دیده می‌شود؛ مدل دلخواه را هم از همان‌جا انتخاب می‌کنی (بعداً می‌شود
مدل‌های غیررایگان را هم به فهرست افزود).

### استقرار تابع

```bash
supabase secrets set OPENROUTER=sk-or-...
supabase functions deploy diary --no-verify-jwt
```

جدول مربوطه:

```sql
-- supabase/ai.sql  → reel_ai_runs
```

تا وقتی تابع مستقر نشود، پنل هوش مصنوعی با پیام فارسیِ روشن می‌گوید «سرویس مستقر نشده
است» و بقیهٔ برنامه دست‌نخورده کار می‌کند.

---

## دست‌نزدن به برنامهٔ دیگر در همان پروژه

یک پروژهٔ Supabase می‌تواند چند محصول بی‌ربط را سرو کند. ریل کنار می‌ماند:

* همهٔ جدول‌ها پیشوند `reel_` دارند و هیچ سیاستی جدول غیر `reel_` را نمی‌خواند؛
* باکت `reel-media` است و مسیر هر شیء با شناسهٔ کاربر شروع می‌شود
  (`<user-id>/frames/YYYY/MM/<uuid>.webp`)؛
* نشست مرورگر زیر کلید اختصاصی خودش (`reel.auth.v1`) ذخیره می‌شود، پس ورود در ریل
  نشست برنامهٔ دیگر را عوض نمی‌کند؛
* سرصفحهٔ شناسهٔ برنامه فرستاده می‌شود (`x-client-info: reel-web/1.0`).

ورود با یک حساب در هر دو برنامه بی‌اشکال است — حساب‌ها مشترک‌اند، داده‌ها نه.

## عکس‌ها

هر تصویر پیش از ذخیره از `js/lib/images.js` می‌گذرد:

* ضلع بلند به **۷۲۰ پیکسل** می‌رسد — تصویر کوچک‌تر بزرگ نمی‌شود؛
* به WebP (با فالبک JPEG) با کیفیت ۰٫۸۶ تبدیل می‌شود؛
* EXIF با رمزگذاری دوباره حذف می‌شود، از جمله مختصات GPS؛
* فایل اصلی هرگز بارگذاری نمی‌شود.

هر قاب تا دوازده عکس می‌گیرد. یکی جلد می‌شود و برای هر عکس می‌توان زیرنویس گذاشت.

## چه چیزی در آن هست

**روایت**
* حساب: ایمیل و گذرواژه، پیوند جادویی، بازیابی گذرواژه، تغییر گذرواژه با پیوند بازیابی
* قاب: تاریخ شمسی، ساعت، عنوان، متن غنی با نوار قالب‌بندی، حال‌وهوا، انرژی، امتیاز،
  آب‌وهوا، مکان، آدم‌ها، برچسب، رشته، تا ۱۲ عکس، انتخاب جلد، زیرنویس
* ثبت سریع از نمای کلی (⌘↵ برای ذخیره)
* پیش‌نویس خودکار آفلاین، تکرار، دوست‌داشتنی، سنجاق، حذف
* جست‌وجوی کامل و صافی بر پایهٔ حال‌وهوا / سال / برچسب / دوست‌داشتنی / سنجاق، سه
  تراکم فهرست، بارگذاری تدریجی، قاب تصادفی
* خواندن با رفتن به قاب قبلی/بعدی، چاپ، برون‌بری Markdown و JSON
* رشته‌ها: قوس‌های داستانی با جلد، توضیح، رنگ و نمای خط داستان
* مکان‌ها: اطلسی ساخته‌شده از مکان قاب‌ها
* آلبوم: چیدمان آجری همهٔ عکس‌ها با نمایش تمام‌صفحه (← →، Esc، دانلود)
* تقویم: جدول ماه شمسی با بندانگشتی و نقطهٔ حال‌وهوا، پنل هر روز
* بینش: قاب و واژه در هر ماه، دونات حال‌وهوا، ریتم روزهای هفته، ابر برچسب، مکان‌ها،
  رکوردها و جمع‌ها — همه با نمودارهای canvas دست‌نویس
* نمای کلی: سلام، زنجیرهٔ روزها، شبکهٔ گرمای ۲۰ هفته، حلقهٔ قصد هفتگی، «در چنین روزی»،
  قاب‌های سنجاق‌شده و پیشنهادهای نوشتن

**صنعتِ کار**
* سه پوسته (روشن / تاریک / سامانه)، شش رنگ امضا، تراکم و اندازهٔ متن، کاهش حرکت
* پالت فرمان (⌘K)، میان‌برهای کیبورد، پیام کوتاه، پنجره، پاپ‌اور، کشوی موبایل
* پشتیبانی آفلاین با سرویس‌ورکر؛ نصب‌شدنی به‌عنوان PWA؛ شیوه‌نامهٔ چاپ
* برون‌بری JSON، Markdown، CSV یا کتاب HTML چاپی؛ وارد کردن آرشیو JSON
* حالت خالی، بارگذاری و خطا در همه‌جا

## محدودیت‌هایی که خوب است بدانی

* سروری نیست، پس حذف **حساب** در داشبورد Supabase انجام می‌شود (پیوندش در تنظیمات است).
  حذف *داده* در خود برنامه است.
* تشخیص جدول‌های ابری با کاوش انجام می‌شود؛ اگر اسکریپت اجرا نشده باشد، برنامه در حالت
  محلی می‌ماند و در ریل همین را می‌گوید.
* پیوند ورود و بازیابی گذرواژه از همین origin استفاده می‌کنند — دامنه‌ای که رویش مستقر
  می‌کنی باید در Supabase → Authentication → URL configuration مجاز باشد.
* کلید publishable در `js/config.js` عمداً عمومی است؛ چیزی که داده را حفظ می‌کند
  row level security است. هرگز کلید secret/service را در سایت ایستا نگذار.
* مانيفست PWA در پیش‌نمایش `*.style.dev` با ۴۰۳ برمی‌گردد؛ این اثر پروکسی است و روی
  دامنهٔ واقعی رخ نمی‌دهد.
